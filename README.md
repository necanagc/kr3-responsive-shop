# МузТорг Жуковский

Учебный адаптивный многостраничный сайт магазина музыкальных инструментов и оборудования. Проект выполняется в рамках контрольной работы №3 по теме «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Страницы и файлы

```text
index.html                 Главная страница
catalog.html               Каталог и фильтры
product.html               Страница товара; выбранный товар задаётся параметром product
orders.html                Форма заявки
contacts.html              Контактная информация
css/style.css              Основные стили
css/responsive.css         Адаптивные стили
js/main.js                 Модальное окно, формы и данные товаров
images/                    Изображения сайта
lighthouse/                HTML-отчёты Lighthouse Accessibility
sitemap.xml                Карта сайта
подготовка-к-защите.md     Конспект для защиты, включая разбор позиционирования
.gitignore                 Игнорирование системного .DS_Store
```

Страница товара открывается из каталога, например `product.html?product=behringer`. Без параметра показывается микшер Behringer. Поддерживаются значения `behringer`, `shure` и `dj-controller`. Путь `orders.html` сохранён; отдельная страница `order.html` не создавалась.

## Адаптивные решения

- Используется подход Mobile First и отдельный `css/responsive.css`.
- На мобильных навигация открывается нативным выпадающим меню; на широких экранах ссылки располагаются рядом с логотипом.
- Размер основного текста и заголовков адаптируется с помощью `clamp()`, а шапка компактно перестраивается на узких экранах.
- Hero выбирает изображение для мобильного, планшетного и широкого экранов через `<picture>`.
- Карточки товаров меняют число колонок на ширинах 640, 1024 и 1280 px.
- Изображение микшера использует `srcset` и `sizes`.
- Каталог складывает фильтр над товарами на узком экране.
- Формы переходят с одной колонки на две от 768 px; таблица характеристик прокручивается внутри своего контейнера.
- Модальное окно ограничено высотой окна браузера.

Проверенные контрольные ширины: 360, 430, 768, 1024 и 1440 px.

## Доступность

- На страницах есть ссылка пропуска к основному содержимому и основной заголовок `h1`.
- Для текущей страницы в навигации используется `aria-current="page"`.
- Для изображений заданы осмысленные `alt`; декоративный логотип имеет пустой `alt`.
- Поля форм связаны с подписями; сообщения об успешной отправке имеют `role="status"`.
- Для интерактивных элементов предусмотрен заметный `:focus-visible`; для пользователей, предпочитающих уменьшенное движение, отключена плавная прокрутка.
- Таблица товара содержит подпись, заголовки строк и столбцов.

## Проверки

Lighthouse Accessibility: 100/100 для `index.html`, `catalog.html`, `orders.html` и `product.html`. HTML-отчёты сохранены в папке `lighthouse/`.

Формы работают в демонстрационном режиме: данные не отправляются и не сохраняются.
